Want a Coin/Gems rainer? no problemo cuz i just made a program for you
Feature:
Coins rainers
Gems rainers

Tutorial:
1. You have to install python ver3.8 or higher
2. than make a folder name k2c or whatever tou like and download the program k2c_coin_editor.py and put it in k2c folder
3. open your game save data C:\Users\your name\AppData\LocalLow\noio\KingdomTwoCrowns\Release and then copy the game save file on the k2c folder
4. Don't forget to backup the save file game data
5. Than run the k2c_coin_editor.py on CMD or Powershell CD C:\k2c
6. heres the command:
   python k2c_coin_editor.py global-v35 --list (for the list)
   python k2c_coin_editor.py global-v35 --player 1 --coins 100 (fot the coin)
   python k2c_coin_editor.py global-v35 --player 1 --gems 100 (for the gems)
7. if you done with the program, then move the game save file to your C:\Users\your name\AppData\LocalLow\noio\KingdomTwoCrowns\Release then replace
8. Run your game and enjoy :)
